### 2026-11-07 — владение 3D передано MiniMax

- Статус: принято
- Контекст: текущий 3D слабый для оценки дизайна; нужно чётко разделить работу.
- Решение: **MiniMax — единственный владелец** `SeatView3D` / сцены / материалов / света / камеры в сцене / анимаций. **Cursor больше не разрабатывает 3D**; отвечает за backend, данные, схему, покупку, `App` wiring, сборку. Контракт данных v1 сохраняется (`hall`, `cameraView`, `occupiedSeatIds`). Приоритеты: P0 покупка + качественный 3D; P1 SeatMatch; P2 SeatCompare/SpatialSound; P3 HonestView. Правила в шести файлах протокола **заменяют** старое распределение.
- Последствия: Cursor не правит 3D без согласования; MiniMax может cherry-pick коммит правил; черновой `SeatView3D.tsx` на `feat/cursor-core` перейдёт MiniMax для переработки.
- Автор: cursor
