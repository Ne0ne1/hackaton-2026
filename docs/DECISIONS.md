## Журнал

### 2026-11-06 — как распределяется работа агентов

- Статус: принято
- Контекст: на хакатоне нужно ставить задачи в одном окне Cursor и реже переключать ИИ вручную.
- Решение: Cursor сам делает интерфейс, backend, интеграции, тесты и обычные правки. Codex подключается официальным CLI (`scripts/run-codex.sh`) для архитектуры, сложных ошибок, аудита и готовности. OpenRouter не подключён и используется только после явного подтверждения расхода API, когда лимит подписки уже исчерпан. Общий контекст ведётся в `docs/TASKS.md` и `docs/DECISIONS.md`. Один файл одновременно редактирует один исполнитель.
- Последствия: автоматический запуск Codex возможен, пока CLI установлен и выполнен вход. Обход песочницы, смена модели ради обхода лимита и вызов платного API без подтверждения запрещены.
- Автор: cursor
