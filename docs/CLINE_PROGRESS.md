### 2026-11-07 — 3D-зал: реалистичный кинозал в концепции «Cinematic Luxury»

- Задача Codex / цель: P0 — переработать 3D-сцену из набора прямоугольников в убедительный современный кинотеатр: правильная камера с места, процедурные кресла, архитектура зала, 3D-экран, премиальная палитра.
- Модуль: 3D-сцена (`SeatView3D` + `src/scene/**`)
- Статус: done
- Изменено:
  - `src/scene/hallGeometry.ts` (новый) — геометрия зала, **вычисляемая из `HallGeometry`**: границы, уровень пола, проходы, расстановка кресел. Учтено ограничение контракта: `Seat.position` — это положение **глаз** зрителя, поэтому основание кресла = `position.y − 1.15` (рост сидящего), пол = минимальная высота глаз минус рост сидящего. Отдельных массивов координат нет.
  - `src/scene/CinemaSeat.tsx` (новый) — процедурное кресло: закруглённое основание, мягкое сиденье, наклонённая спинка, подлокотники, опоры. Части рендерятся через Drei `Instances` (инстансинг) с per-instance цветом (`instanceColor`), поэтому 96 кресел дают единицы draw call. Разные материалы обивки по категориям места (VIP / Комфорт / Стандарт), отдельный тон для занятого и выбранного места.
  - `src/scene/HallArchitecture.tsx` (новый) — пол + ковровая зона, боковые/задняя/передняя стены, потолок, акустические панели, подсветка проходов (светящаяся полоса + тёплые точечные источники), подиумы рядов (ступени строятся, только если ряды в данных стоят выше базового пола).
  - `src/scene/ScreenPanel.tsx` (новый) — экран как настоящий 3D-объект: плоскость ровно `hall.screen.width × height` (без искажений), «шторки» сверху и снизу, мягкое тёплое свечение в зал, два источника света (ближний яркий + широкий слабый), чтобы экран оставался видимым с последнего ряда.
  - `src/scene/SeatCameraRig.tsx` (новый) — **исправление камеры**. Раньше позиция выставлялась на `useThree().camera`, а рендерилась отдельная `<PerspectiveCamera makeDefault>` — это разные объекты, из-за чего камера «отъезжала» от выбранного места. Теперь камера одна (с `makeDefault`), ей же управляем. Переезд между местами — плавная интерполяция позиции, цели и fov в `useFrame` (900 мс, ease-in-out), после анимации камера **точно** совпадает с выбранным местом.
  - `src/components/SeatView3D.tsx` — переписан: сборка сцены из новых модулей, свет (ambient + hemisphere + направленный с мягкими тенями 1024² + заполняющий сзади + тёплый акцент), туман, золотой ореол выбранного места, подпись с номером ряда и места. Внешний интерфейс не изменён: `hall`, `cameraView`, `occupiedSeatIds`.
  - `src/components/SeatView3D.css` (новый) — оформление 3D-панели: адаптивная высота, мягкие градиенты, тонкая золотая линия по контуру, подпись на фоне панели. Переопределяет базовый `.view-3d` из `styles.css` (файл ядра не изменялся).
  - `docs/CLINE_PROGRESS.md` — эта запись.
